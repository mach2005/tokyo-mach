# 東京真隼 Webデザイン・実装方針

本ファイルは `東京真隼` プロジェクト固有のWebデザインおよび画面レイアウト実装ルールを定義します。

---

## 1. レスポンシブデザイン（スマホ最適化）の徹底
* モバイル表示（スマートフォン・タブレット）でのレイアウト崩れや操作性の低下を防ぐため、常にレスポンシブデザインを意識したCSS/HTMLを記述すること。
* ビューポート調整、フレキシブルレイアウト（Flexbox / Grid）、適切なタッチターゲットサイズを確保すること。

---

## 2. デザインの統一性
* 既存のテーマカラーやスタイル設定を損なわないよう、コード変更・追加時には既存のCSS設計スタイルに合わせること。
