# 東京真隼（TOKYO MACH）ユーザー過去指示・永久遵守ナレッジ

このドキュメントは、過去のすべてのチャットやり取り・ユーザーからの指摘事項をデータベース化し、AIが新しいセッションでも100%厳守するためのナレッジベースです。

## 1. 文字コード・ファイル編集ルール
- **PowerShell編集の禁止**: PowerShellの `Set-Content`, `Get-Content`, `>`, `>>` による操作は UTF-16LE 文字化けを引き起こすため、絶対に使用しないこと。
- **ファイル書き換え**: 必ず AI専用ツール（`replace_file_content` 等）または Python (`open(..., encoding='utf-8')`) を使用すること。

## 2. デザイン・表記の保全ルール
- **フッター統一**: 全サブページ（`songs.html`, `schedule.html`, `faq.html`, `gallery.html`）のフッター左下の記述は、常に公式HP（`official/index.html`）の「ホークスのビジター全試合で応援活動を行います。」に100%一致させること。
- **ネクストビジターバッジ**: トップページのネクストビジター欄は、「NEXT VISITOR」のラベルで、本日の日付以降の「次回行われるビジター試合（例: 8/7 (金) vs 西武 ベルーナドーム）」を表示させること。スクリプト実行等により勝手にスコア付きの「LATEST VISITOR」や過去試合に退化させないこと。
- **スケジュール矢印**: スケジュールナビゲーションの矢印は「黒カプセル型（ピル形状）」を維持すること。
- **要素の勝手な非表示禁止**: モバイル最適化時などに既存の文字情報やロゴを無断で非表示（`display: none` 等）にしないこと。

## 3. 自動バックアップ＆即時復元ルール
- **事前バックアップ**: HTMLファイルの修正を行う前に、必ず `python develop/backup_manager.py` を実行して直前状態を保存すること。
- **即時ロールバック**: ユーザーから「戻して」「ロールバック」と言われた場合は、即座に `python develop/backup_manager.py restore` を実行して即座にデプロイまで完遂すること。

## 4. データ更新とビルド連動ルール
- **日程更新**: `develop/data.txt` を編集すると `build_pages.py` が自動パースして `schedule.html` が更新される。二重管理のズレを起こさないこと。
- **全自動0時更新**: 毎日0:15に GitHub Actions が自動起動し、`update_x_feed.py`（Twitter最新投稿）、`update_ig_feed.py`（Instagram最新投稿）、`update_game_result.py`（最新結果・ネクストビジター・カレンダー）を一括自動実行・デプロイする。
